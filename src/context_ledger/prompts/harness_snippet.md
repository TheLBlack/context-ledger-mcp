## Context Ledger

When Context Ledger MCP tools are available, use them as durable memory for the repository or shared scope configured by that MCP connection:

- Before planning or changing code, call `get_project_context` with a concise description of the task.
- Use `search_memory` when broader or historical context may matter.
- Record only durable conclusions that will help a later session; never store transcripts or routine progress.
- Preserve evidence authority: do not turn an observation or inference into a user decision. Supersede obsolete records and dispute unresolved conflicts.
